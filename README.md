# Hack XZZD

学在浙大自动刷课

## 使用方法

1. 安装[Tampermonkey](https://www.tampermonkey.net/)或[ScriptCat](https://scriptcat.org/)

2. 点击这个链接安装脚本：<https://github.com/cyhkbl/Hack_XZZD/raw/refs/heads/main/hack_xzzd.user.js>

3. 打开课程页面或某一个视频的页面

4. 按下按钮就可以自动刷课

5. 缩小到任务栏，可以边做其他事情边刷课

## 倍速播放

经检验超过2倍速是不计入观看的，所以可以卡着2倍速看。如果调速度有bug，还可以安装[视频倍速播放控制器](https://chromewebstore.google.com/detail/%E5%80%8D%E9%80%9F%E6%92%AD%E6%94%BE%E6%8E%A7%E5%88%B6%E5%99%A8/lhjgkfafnanbifnnbbhfanffipagpjai)调节视频播放速度。
